# Method and software documentation consulted

The source scripts in `legacy/` determine the model inputs, descriptors and explicit hyperparameters. These references inform software packaging and interpretation of reproducibility, rather than supplying replacement study data.

- Scikit-learn, Common pitfalls: https://scikit-learn.org/stable/common_pitfalls.html
- Scikit-learn, Cross-validation: https://scikit-learn.org/stable/modules/cross_validation.html
- Scikit-learn, Model persistence: https://scikit-learn.org/stable/model_persistence.html
- CatBoost, regression API: https://catboost.ai/docs/en/concepts/python-reference_catboostregressor
- CatBoost, model loading: https://catboost.ai/docs/en/concepts/python-reference_catboost_load_model
- Springer Nature, Code Policy: https://www.springernature.com/gp/open-science/code-policy

Consulted 2026-10-09. Saved versions are documented in each run's `environment.json`; a current web documentation version may be newer than the tested environment. This package is not certified or approved by a journal.
